# 网盘二维码右键直链 (Pan QR Right-Click)

一款**零常驻开销、纯本地离线、按需触发**的 Chromium（Chrome / Edge / CentBrowser）Manifest V3 浏览器扩展。

在网页上遇到以二维码图片形式分享的百度网盘、夸克网盘、迅雷云盘、阿里云盘等资源时，**右键点击二维码图片即可毫秒级解析并直接在新标签页打开网页链接**，免去手机扫码，也不破坏原网页排版。

## 核心特性

* **平时 100% 零开销**：无常驻 `content_scripts`，无网络拦截钩子，无定时器；不点右键时后台 Service Worker 完全休眠，**0 CPU、0 带宽、不影响任何网页和图片加载速度**。
* **毫秒级极速打开（零多余网络请求）**：
  1. 在线二维码 API 参数直取（`<1ms`）
  2. `data:` Base64 图片本地直解
  3. 并行本地帧缓冲截屏（`captureVisibleTab`）+ DOM 坐标精准裁剪解码（约 `30~60ms`，绕过跨域缓存分区，无需重新联网下载图片）
  4. 极端情况（二维码被滚出视口截断）自动降级为后台原图拉取兜底
* **专为网盘分享优化**：
  * 支持百度网盘、夸克网盘、阿里云盘、123云盘、迅雷云盘、蓝奏云、天翼云盘、UC网盘、PikPak；
  * 自动将百度网盘移动端链接（`/wap/init?surl=...`）规范化为电脑网页直链（`/s/1...`）；
  * 若二维码内未附带 `pwd`，自动在当前二维码所在的**单列卡片**内查找并补全 4 位提取码（严格隔离防止跨列串台）。
* **纯本地离线 & 隐私安全**：内置 `jsQR` 与原生 `BarcodeDetector`，**不向任何第三方服务器上传图片**。
* **Canvas / SVG 二维码兜底**：遇到个别网站不是 `<img>`、而是用 `<canvas>` 或 `<svg>` 绘制的二维码时，点击浏览器右上角扩展图标即可按需扫描当前页。

## 安装方式（Chrome / Edge / CentBrowser）

1. 前往 [Releases](../../releases) 下载最新的 `pan-qr-rightclick-ext-v1.1.0.zip` 并解压到本地目录（或直接 `git clone` 本仓库）。
2. 在浏览器地址栏打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
3. 打开右上角 **「开发者模式」**，点击左上角 **「加载已解压的扩展程序」**，选择解压后的文件夹即可。

## 使用方法

* **普通图片二维码**：在任意二维码图片上点击 **鼠标右键**，选择：
  * **「识别二维码并打开链接」**：立即在新标签页打开解析出的网页链接，同时顺手复制到剪贴板；
  * **「识别二维码并复制链接」**：仅复制解析结果，不跳转页面。
* **Canvas / SVG 二维码**：点击浏览器右上角蓝色二维码图标，按需扫描当前页面。

> **说明**：仅支持标准方形 QR Code；微信私有的圆形「小程序码（太阳码）」无法通过标准二维码算法离线解码。

